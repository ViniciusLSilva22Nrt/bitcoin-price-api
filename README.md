📊 Bitcoin Price API Consumer

Projeto desenvolvido para consumir dados do valor do Bitcoin em tempo real a partir de uma API pública, com foco em coleta, tratamento e persistência de dados para análises futuras.

🚀 Objetivo do Projeto

Consumir dados atualizados do preço do Bitcoin

Estruturar os dados para uso em análise de dados

Praticar conceitos de:

Consumo de APIs

Manipulação de dados

Automação de coleta

Integração com banco de dados 

🛠️ Tecnologias Utilizadas

Python

Requests – consumo da API

Pandas – tratamento e organização dos dados

PostgreSQL – persistência dos dados

SQLAlchemy 

dotenv – gerenciamento de variáveis de ambiente
